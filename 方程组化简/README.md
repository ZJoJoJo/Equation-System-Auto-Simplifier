# 方程组自动化简软件

一款简约风格的电脑端桌面方程组自动化简软件，核心聚焦方程组精准化简、自定义运算输出。

## 功能特性

### 一、核心基础功能
- **批量输入多元方程组**：支持整式、分式、多项式、多元联立方程组的逐级化简、消元、合并运算
- **下划线自定义下标**：支持 `v_1`、`R_123`、`a_xy`、`node_1a` 等任意长度数字/字母组合下标
- **希腊字母变量**：在希腊字母名称前加 `/` 即识别为变量，如 `/beta` → β、`/gamma` → γ（直接输入 `beta` 保持为 SymPy 数学函数）
- **智能变量识别**：自动扫描所有方程，精准统计识别全部独立变量
- **隐式乘法支持**：输入 `2x` 自动识别为 `2*x`

### 二、自定义进阶功能
- **中间变量屏蔽**：标记的中间变量全程参与运算推导，但最终输出中自动彻底剔除
- **目标结果指定**：支持单一变量（`v_1`）、变量分式（`v_1/v_2`）、多变量组合（`v_1 + v_2`）
- **同类项合并**：指定特征变量，自动将所有包含该变量的项归类合并

### 三、公式渲染
- **LaTeX/KaTeX 双兼容**：所有输入、结果实时渲染
- **多字符下标修复**：`v_12` 完整渲染为 `v_{12}`
- **希腊字母渲染**：`/beta` 渲染为 β，`/beta_1` 渲染为 β₁

### 四、界面风格
- 极简简约风格，四大功能分区
- 底部可折叠「输入帮助」面板，随时查阅输入规范
- 本地离线 KaTeX 渲染，无需联网

## 运行方式

### 方式一：exe 启动器（推荐，双击即用）
双击 `方程组自动化简.exe`，将以独立桌面窗口启动。

启动器会自动检测并设置运行环境：
- 首次运行时自动创建 `.venv` 虚拟环境并安装依赖（需联网，约 1-2 分钟）
- 后续运行直接使用 `.venv`，秒级启动
- 若 `.venv` 损坏，自动重建

### 方式二：命令行启动
```bash
# 桌面窗口模式
python app.py

# 浏览器模式
python app.py --web
```

## 移植到其他电脑

### 系统要求
- Windows 10/11
- Python 3.8 或更高版本（安装时勾选 "Add Python to PATH"）
- 首次运行需联网（自动安装依赖）

### 移植步骤
1. 将整个文件夹（**不包含 `.venv`**，因为虚拟环境不可移植）复制到目标电脑
2. 确保目标电脑已安装 Python 3.8+
3. 双击 `方程组自动化简.exe`
4. 首次运行会自动创建 `.venv` 并安装依赖，等待 1-2 分钟
5. 之后每次双击即可直接运行

> **注意**：如果复制时包含了 `.venv`，启动器会检测到它但可能因路径不匹配而无法使用，此时会自动删除并重建。建议传输时排除 `.venv` 文件夹以减小体积。

## 输入帮助

### 希腊字母变量
在希腊字母名称前加 `/` 即识别为变量：

| 输入 | 显示 | 输入 | 显示 |
|------|------|------|------|
| `/alpha` | α | `/mu` | μ |
| `/beta` | β | `/nu` | ν |
| `/gamma` | γ | `/xi` | ξ |
| `/delta` | δ | `/pi` | π |
| `/epsilon` | ε | `/rho` | ρ |
| `/zeta` | ζ | `/sigma` | σ |
| `/eta` | η | `/tau` | τ |
| `/theta` | θ | `/phi` | φ |
| `/iota` | ι | `/chi` | χ |
| `/kappa` | κ | `/psi` | ψ |
| `/lambda` | λ | `/omega` | ω |

支持带下标：`/beta_1` → β₁

> 直接输入 `beta`、`gamma` 等保持为 SymPy 内置数学函数，不会被识别为用户变量。

### 基本运算
| 输入 | 含义 |
|------|------|
| `+ - * /` | 加减乘除 |
| `x^2` 或 `x**2` | x 的平方 |
| `2x` | 2 × x（隐式乘法） |
| `(x+1)(x-1)` | (x+1) × (x-1) |

### 常用函数
| 输入 | 含义 |
|------|------|
| `sqrt(x)` | 平方根 √x |
| `sin(x) cos(x) tan(x)` | 三角函数 |
| `exp(x)` | 指数 eˣ |
| `log(x)` | 自然对数 ln x |
| `abs(x)` | 绝对值 \|x\| |

### 下标变量
用下划线 `_` 表示下标，下划线后所有字符均为下标：
- `v_1` → v₁
- `R_12` → R₁₂（多位数下标）
- `a_xy` → a_xy（字母下标）

### 方程组格式
- 每行一个方程，用 `=` 分隔
- 以 `#` 开头的行为注释
- 空行自动忽略

### 自定义参数
- **中间变量**：参与运算但结果中屏蔽，如 `V_1, V_2`
- **目标结果**：指定输出形式，如 `V_o/V_i`
- **合并变量**：按指定变量合并同类项
- **Ctrl+Enter**：快捷执行化简

## 示例

### 电路 s 域传输函数（含希腊字母）
```
V_1 = (g_m*/beta*r_0*V_i + s*C*r_0*V_o) / (1 + s*C*r_0)
s*C*V_1 = (g_m4 + s*C + 1/r_o4)*V_o - g_m4*V_2
g_m4*V_o = g_m3*V_1 + (g_m4 + 1/r_o3 + 1/r_o4)*V_2
```
- 中间变量：`V_1, V_2`
- 目标结果：`V_o/V_i`

输出完整 s 域传输函数，β 正确渲染为希腊字母。

## 项目结构

```
TEST/
├── 方程组自动化简.exe      # 桌面启动器（双击运行，自动设置环境）
├── launcher.cs             # 启动器 C# 源码
├── app.py                  # Flask 后端 + pywebview 桌面入口
├── requirements.txt        # Python 依赖清单
├── run.bat / run_web.bat  # 备用启动脚本
├── core/
│   ├── __init__.py
│   └── engine.py           # 核心化简引擎（解析、消元、希腊字母、渲染）
├── templates/
│   └── index.html          # 前端主页面（含输入帮助面板）
├── static/
│   ├── css/style.css       # 极简风格样式
│   ├── js/app.js           # 前端交互逻辑
│   └── vendor/katex/       # KaTeX 本地离线资源（含字体）
├── tests/
│   └── test_features.py    # 全面功能验证测试（64项）
└── .venv/                  # 虚拟环境（首次运行自动创建，不可移植）
```

## 技术栈
- **后端**：Python 3 + Flask + SymPy（符号计算）
- **前端**：HTML + CSS + JavaScript + KaTeX（公式渲染）
- **桌面包装**：pywebview + waitress（生产级 WSGI 服务器）
- **启动器**：C# 编译的原生 exe（自动环境检测与设置）
